# Changelog

User-visible changes are recorded here. Version numbers follow the extension
manifest and `extension/package.json`.

## Unreleased

### Added

- Manifest V3 extension for collecting images from an open comic reader tab.
- Reader image previews, page selection, and optional container selectors.
- CBR (RAR 5 store) and CBZ (ZIP store) export with sequential page filenames.
- Requests using the reader session, optional image-host access, progress, and cancellation.
- Archive interoperability tests and tests for reader discovery and download behavior.
- Public documentation, community policies, issue templates, and CI.
