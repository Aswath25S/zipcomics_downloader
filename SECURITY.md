# Security policy

## Supported code

Security fixes target the latest code on the default branch and the latest
release. Older releases may require an update to receive a fix. This community
project does not promise a response deadline.

## Report a vulnerability

Use **Security → Advisories → Report a vulnerability** on this project's GitHub
repository when private vulnerability reporting is enabled. Describe the affected
version, impact, reproduction steps, and a small proof of concept if available.

If that option is unavailable, use a private contact method listed on a
maintainer's GitHub profile. If none is listed, open an issue titled **Private
security contact requested** without exploit details or sensitive information.
Arrange a private channel before sharing the report.

Do not post browser cookies, authorization headers, signed image URLs, private
comic URLs, or personal data in a public report.

Relevant issues include script injection through page content, access beyond
requested permissions, unintended transmission of browsing or image data, and
unsafe archive filenames. An image host refusing a download or a verification
page preventing access is normally a compatibility issue.

## Maintainer setup

Before publishing the repository, enable GitHub private vulnerability reporting
and provide a private contact method on a maintainer's profile. Enabling the
GitHub setting requires repository access; this file does not enable it.
