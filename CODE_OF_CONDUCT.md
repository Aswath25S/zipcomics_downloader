# Code of conduct

Everyone participating in this project should be able to contribute without
harassment or discrimination. This applies to issues, pull requests, discussions,
reviews, and other project spaces, and when representing the project elsewhere.

## Expected behavior

- Treat people respectfully, including when you disagree.
- Give specific, constructive feedback about the work.
- Respect different backgrounds, abilities, experiences, and levels of knowledge.
- Protect other people's privacy and respect their boundaries.
- Follow maintainer guidance about keeping discussions relevant and productive.

Harassment, discriminatory language, personal attacks, threats, sexualized
comments, doxxing, and sustained disruptive behavior are not acceptable.

## Reporting and enforcement

Report conduct concerns privately to a repository maintainer using a contact
method listed on their GitHub profile. If no private contact method is available,
open an issue requesting one without naming individuals or describing sensitive
details publicly. If the concern involves a maintainer, contact another maintainer
when one is available.

Maintainers should handle reports discreetly, consider the evidence and context,
and communicate appropriate next steps. They may edit or remove content, request
changes in behavior, restrict participation, or remove participants from project
spaces. The response should reflect the severity and recurrence of the behavior.
